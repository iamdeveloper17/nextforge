# Contributing to NextForge

First off — thank you for considering contributing! 🎉

## How to Contribute

### Reporting Bugs

Before creating a bug report:
- Check if the issue already exists in [Issues](https://github.com/iamdeveloper17/nextforge/issues)
- Use a clear, descriptive title
- Include steps to reproduce, expected vs actual behavior, and screenshots if applicable

### Suggesting Features

Feature requests are welcome! Open an issue with:
- Clear description of the feature
- Why it would be useful
- Any implementation ideas

### Pull Requests

1. Fork the repo and create a branch from `main`:
   ```bash
   git checkout -b feat/your-feature-name
